# 🐾 Adopt me - Adoção Animal

O **Amigos da Mia** é um projeto de site responsivo desenvolvido para uma ONG fictícia de proteção animal. O foco principal foi criar uma interface intuitiva, acessível e totalmente adaptável a dispositivos móveis, facilitando a conexão entre animais resgatados e possíveis adotantes.

---

## 🚀 Funcionalidades

* **Home Informativa:** Banner principal com call-to-action para incentivar a adoção.
* **Galeria de Animais:** Listagem de pets disponíveis com cards detalhados.
* **Seção de Doações:** Informações claras sobre como ajudar a ONG financeiramente ou com suprimentos.
* **Design Responsivo:** Navegação fluida tanto em desktops quanto em smartphones, utilizando o sistema de grid do Bootstrap.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas de desenvolvimento Web:

* **HTML5:** Estruturação semântica de todo o conteúdo.
* **CSS3:** Estilização personalizada e animações suaves.
* **Bootstrap 5:** Framework principal para agilidade no layout e sistema de colunas.
* **Flowbite:** Componentes interativos e modernos baseados em Tailwind CSS para dar um acabamento premium.
* **Google Fonts:** Tipografia selecionada para melhorar a legibilidade e o apelo visual.

---

## 🏗️ Conceitos Aplicados (ADS)

* **Mobile First:** Priorização da experiência em telas menores.
* **UI/UX Design:** Foco na jornada do usuário para garantir que o processo de "encontrar um pet" seja simples.
* **Acessibilidade:** Uso de tags semânticas e contraste de cores adequado.

---


## 📝 Como visualizar

2. Abra o arquivo `index.html` em qualquer navegador moderno.
